# Tutorial cover

`medium-cover.png` is an original AI-generated editorial illustration for the author's own task-list tutorial, created using the built-in image-generation tool. It is not an application screenshot. The selected image removes a generated Flutter-style logo; there is no third-party logo in the final cover. Existing application screenshots remain in `../screenshots/`.

Initial prompt: wide approximately 2:1 Brazilian Portuguese classroom tutorial cover; cream, forest green and sage; layered task cards with checks and a database illustration; exact title “Lista de tarefas com Flutter”, subtitle “Do primeiro widget ao SQLite”, footer “Notas de aula • Kleber Andrade”; generous whitespace, no stock watermark, no mock device screenshots, no third-party logo.

Final edit prompt: remove only the stylized Flutter logo from the upper-left cream area; preserve all text, task cards, database, palette and framing; add no replacement logo.

`save-flow.svg` and `database-migration.svg` are editable, code-authored diagrams of this repository's existing save flow and schema v1→v2 migration. Their PNG exports were rasterized with Sharp, then visually checked. The example ID 42 in the migration diagram is explicitly illustrative. These diagrams are explanations, not app screenshots.

The Medium article embeds the cover, two diagrams, the real 390px form capture and the current Web desktop capture. The form image is a responsive browser capture from the original modernization, not a physical device screenshot. Diagram SVGs remain editable sources; the cover illustration is explicitly distinguished from real application imagery.
